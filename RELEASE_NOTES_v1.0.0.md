# Connection Check v1.0.0

Initial public release.

## Highlights

- Real internet outage monitoring
- Turkish / English interface
- Daily outage logs
- Outage duration tracking
- Daily counter reset with versioned log files
- System tray support
- Optional Windows startup
- Single-instance protection
- Responsive interface for smaller screens
- LocalAppData-based settings and logs

## Windows Downloads

Recommended release assets:

- `Connection-Check-v1.0.0-Windows-Portable.exe`
- `Connection-Check-v1.0.0-Windows-Fast.zip`

The Portable build is a single EXE and can take slightly longer to launch.
The Fast build uses the PyInstaller `--onedir` layout and should be extracted before running.
